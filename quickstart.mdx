title: "Build your first swap"

---

Jupiter APIs give you the building blocks for Solana trading: quotes, routes, execution, token data, and pricing.

## Prerequisites

- A server-side runtime such as Node.js 18+
- A Solana wallet for signing transactions
- A Jupiter API key for production traffic

## Get started

<Steps>
  <Step title="Create a project">
    ```bash
    mkdir jupiter-demo && cd jupiter-demo
    npm init -y
    npm install @solana/web3.js
    ```
  </Step>
  <Step title="Request a quote">
    Use the Swap API to find a route. Keep amounts in the token's smallest unit.

    ```bash
    curl "https://api.jup.ag/swap/v1/quote?inputMint=So11111111111111111111111111111111111111112&outputMint=EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v&amount=10000000&slippageBps=50"
    ```
  </Step>
  <Step title="Build and sign">
    Send the selected quote to the swap endpoint, deserialize the returned transaction, sign it locally, and send it to your Solana RPC.
  </Step>
</Steps>

<Tip>
  Start with `slippageBps=50` (0.50%) only as a development example. Choose slippage based on the asset, route, and market conditions.
</Tip>
