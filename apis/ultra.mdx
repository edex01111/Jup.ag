Ultra is designed for integrations that want Jupiter to handle more of the execution lifecycle while they focus on product experience.

Use it when you want a simpler path from order request to execution status. Keep your application responsible for user consent, policy, and clear transaction state.

## When to choose Ultra

- You want a single order lifecycle instead of assembling quote and swap calls.
- You need execution status that your UI can display to users.
- You are building a wallet, trading interface, or automated execution service.
