Token metadata powers search, icons, decimals, verification labels, and portfolio views.

## Use metadata safely

Treat token lists as untrusted input. Validate mint addresses, show decimals correctly, and make it clear when an asset is unverified or has limited liquidity.

## Recommended cache

Cache metadata by mint with an explicit refresh policy. Keep the last known value available for resilient UI, but never use stale metadata to bypass execution checks.
